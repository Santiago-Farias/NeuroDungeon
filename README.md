# NeuroDungeon

A java RPG battle system playable via console.

## Features

- Turn-based combat
- Level system based on the player's accumulated experience
- Enemy scaling by the level of player
- Skills (attack, heavy attack, heal)
- Energy system.

## Technologies

- Java 24
- Netbeans IDE
- OOP

## Quick Start

To run this project, you need to have Java installed.

```bash
1. Clone repo.
   git clone https://github.com/Santiago-Farias/NeuroDungeon.git
   cd NeuroDungeon
2. Compile with: `javac NeuroDungeon.java`
3. Run: `java NeuroDungeon`
```
